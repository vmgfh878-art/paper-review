> Deep learning and process understanding for data-driven Earth system science
> Reichstein, Camps-Valls, Stevens, Jung, Denzler, Carvalhais, Prabhat · Nature 566, 195–204 (2019)
> https://doi.org/10.1038/s41586-019-0912-1

- 분야: 기후
- 읽은 날: 2026-09-16
- 읽은 이유: 교수님과 진행하는 논문 스터디 (기후 5편 중 첫 편).
- 같이 보기: [설명 대본](summary.md) · [예상 질문](questions.md)

**논문 종류가 다르다.** 첫 줄에 **Perspective**라고 적혀 있다.

```
연구 논문 (VMD)    새 방법 제안 → 수식 → 실험으로 증명
Perspective        새 방법도 실험도 없음 → "분야가 이 방향으로 가야 한다"는 주장 + 근거 사례
```

그래서 7번은 실험 대신 **논문이 드는 근거 사례**로 채웠고, Ablation은 해당 없음.
저자도 지구과학자(막스플랑크 생지화학·기상연구소)와 ML 연구자(원격탐사·컴퓨터비전·슈퍼컴퓨팅)의 합작이다.

## 1. 한 줄 요약

지구과학 데이터는 폭증하는데 기존 ML은 공간·시간 맥락을 제대로 못 쓰니,
**딥러닝으로 맥락을 자동 추출하고, 최종적으로는 물리 모델과 ML을 합친 하이브리드 모델로 가자**는 주장.

## 2. 배경 — 이 논문이 나오기까지

### 2-1. 예측은 정체, 데이터는 폭발

```
잘 되는 것:   날씨 예측 — 이론 + 계산력 + 관측 데이터 동화로 크게 발전
안 되는 것:   며칠 너머의 예측, 계절 예측, 홍수·산불 같은 극한 사건, 장기 기후 전망
가장 안 되는 것: 생물권 — 성장·번식 같은 생물 과정, 산불·산사태 같은 교란
             지난 수십 년간 진전이 거의 없음
```

반면 데이터는 저장량 수십 PB 이상, 전송량 하루 수백 TB. 관측(원격탐사·현장·시민과학)에
모델 출력(CMIP-5 3 PB → CMIP-6 30 PB 예상)까지 더해진다.

**빅데이터 4V를 전부 갖춘 대표 사례** (Fig. 1).

| 데이터의 문제 | → | 지식의 목표 |
|---|---|---|
| Volume 크기 | → | 작고 소화 가능하게 |
| Velocity 속도 | → | 실시간은 필요한 곳만 |
| Variety 다양성 | → | 분야를 넘어 통합 |
| Veracity 불확실성 | → | 신뢰도와 강건성 |

Fig. 1은 위아래로 순환 화살표를 둔다. **'Knowledge from data'**(관측에서 패턴을 뽑아 이해)와
**'Data from knowledge'**(이해로 모델을 돌려 시뮬레이션 데이터 생성).

### 2-2. 지구과학 ML의 계보

```
~30년 전   고해상도 위성 + 신경망 첫 부활 → 토지 피복·구름 분류
그 이후    커널 방법, 랜덤 포레스트가 나올 때마다 지구과학에 적용
           → 분류·변화 탐지·이상 탐지의 보편적 도구가 됨
최근 몇 년  딥러닝으로 공간·시간 구조를 쓰기 시작
2019       이 논문
```

### 2-3. 논문이 내건 두 과제

```
과제 (1)  데이터 홍수에서 지식을 뽑아낸다
과제 (2)  기존 데이터 동화보다 데이터에서 훨씬 많이 배우되, 자연 법칙 이해는 존중한다
```

**이 두 과제가 논문 전체 구조다.** (1)은 딥러닝 절들로, (2)는 하이브리드 절로 이어진다.

## 3. 기존 방식의 한계

### 3-1. 조심하면 피할 수 있는 함정

| 함정 | 예 |
|---|---|
| 순진한 외삽 | 0~30°C로 학습한 모델에 폭염 40°C |
| 샘플링·데이터 편향 | 관측 타워가 유럽·북미에 몰린 채 전 지구 예측 |
| 교란 요인 무시 | 아이스크림 판매량과 익사 사고 — 진짜 원인은 더위 |
| 상관을 인과로 해석 | 위와 같은 오류 |
| P-fishing | 변수 100개 검정하면 5개쯤은 우연히 유의 |

논문은 이건 **모범 사례와 전문가 개입으로 피할 것**이라 하고, 진짜 문제는 아래라고 방향을 튼다.

### 3-2. 본질적 한계 — 순간·지점 값만 본다 ★

기존 ML의 전형적 구조는 이렇다.

```
[이 지점, 이 순간의 환경]  →  [이 지점, 이 순간의 결과]
```

현실에서는 결과가 **시스템의 상태**에 좌우되는데, 상태는 잘 관측되지 않아 입력으로 못 쓴다.
그러나 **이전 시간과 이웃 지점에 상태의 흔적이 남아 있다.**

```
오늘 32°C, 습도 40%             → 그냥 더운 날
지난 60일 비 안 옴 + 맑은 날 계속 → 가뭄이라는 상태
  같은 32°C라도 광합성·산불 위험이 완전히 다르다
```

**사례 A — 산불**
```
발생: 순간 기후 + 발화원 + 연료의 상태와 양            ← 시간 맥락
확산: 연료의 공간 배치·연결성, 수분, 지형, 풍속·풍향     ← 공간 맥락
```

**사례 B — 허리케인**
```
대칭적으로 뻗는 바람, 가운데 '눈'
→ 픽셀 하나의 풍속으로는 알 수 없고, 픽셀들이 이루는 모양을 봐야 한다
```

### 3-3. 수작업 피처로 보완하면 생기는 문제

| | 수작업 피처 | 문제 |
|---|---|---|
| 시간 기억 | 적산온도(생물계절), 표준화 강수 지수 SPI(가뭄) | **변수 하나의 기억만** 본다. 여러 변수의 상호작용을 무시 |
| 공간 맥락 | 지형 모양, 지형·질감 피처 | 초기 컴퓨터비전(모서리·질감·모양·색)과 같은 방식 |

수작업 피처의 양면:

```
장점  설명 변수를 통제할 수 있다 — 무엇이 들어갔는지 안다
단점  지루하고 임기응변적이며, 아마 최적이 아니다
      제한적이고 주관적인 선택이라는 우려가 남는다
```

## 4. 핵심 아이디어

### 4-1. 맥락을 딥러닝의 일부로

논문이 딥러닝을 한 문장으로 정의한다.

> **추상적인 (시공간) 피처의 자동 추출**

```
기존: 사람이 맥락 피처를 설계해서 넣는다
제안: 원시 시공간 데이터에서 딥러닝이 스스로 뽑게 한다
```

### 4-2. 지구 데이터는 이미 딥러닝이 잘하는 데이터와 닮았다

| 딥러닝 분야 | ↔ | 지구과학 |
|---|---|---|
| 이미지 — 픽셀마다 RGB 3채널 | ↔ | 2차원 데이터장 — 격자마다 기온·습도·풍속 |
| 비디오 — 이미지의 시퀀스 | ↔ | 시간에 따라 변하는 2차원 장 |
| 자연어·음성 — 다중 해상도 | ↔ | 지구 변수의 동적 시계열 |

### 4-3. 왜 지구과학에서 딥러닝 효과가 더 클 수 있나 ★

논문에서 가장 날카로운 논증.

```
컴퓨터비전에서 수작업 피처가 통했던 이유 = 세상에 대한 명확한 이해가 있었기 때문
  표면과 경계가 존재한다
  3차원이 2차원 사진으로 어떻게 찍히는지 안다
  램버시안 표면 가정: 밝기가 보는 각도에 무관 → 한 점은 시간이 지나도 같은 밝기
  움직임은 대개 강체 변환(모양 유지, 위치·방향만 변함)

지구·기후 과학에는 그런 일반 지식이 아직 부분적으로 없다
  → 그리고 그게 바로 연구로 찾고 있는 것이라, 가정으로 깔 수 없다
```

원문의 결론 한 문장:

> **과정을 잘 이해하지 못할수록, 좋은 수작업 피처를 기대하기 어렵다.**

```
잘 아는 분야 (컴퓨터비전)   수작업 피처가 꽤 통함 → 딥러닝의 이득 = 중간
잘 모르는 분야 (지구과학)   수작업 피처가 안 통함 → 딥러닝의 이득 = 더 큼
```

### 4-4. 그러나 예측만으로는 부족하다 → 하이브리드

```
딥러닝은 곧 시공간 구조를 분류·예측하는 대표 방법이 될 것이다
더 어려운 것은 예측에 더해 이해를 얻는 것,
그리고 데이터에서 최대한 배우면서 물리·생물 지식을 반영하는 모델을 만드는 것
→ 유망하지만 거의 개척되지 않은 길: 머신러닝과 물리 모델의 통합
```

## 5. 구조 / 방법 — 논문의 논증 구조

방법 논문이 아니므로 "모델 구조" 대신 **주장이 쌓이는 순서**를 남긴다.

```
① 예측 정체 + 데이터 폭발 → 두 과제                                  (서론, Fig. 1)
② 기존 ML은 순간·지점만 본다. 맥락은 수작업 피처뿐                     (State-of-the-art)
③ 딥러닝은 맥락을 자동 추출한다. 데이터도 닮았다                        (Opportunities, Fig. 2, Table 1)
④ 그런데 사진과 다르다 → 도전 5가지                                    (Challenges)
⑤ 물리 모델과 합치면 이해까지 갈 수 있다 → 시너지 5지점, 하이브리드      (Integration, Fig. 3, Fig. 4)
⑥ ML이 이론에 도전해 과학을 진전시킨다 → 권고 4가지                     (Advancing science, Conclusion)
```

### 5-1. Table 1이 제시하는 대응 규칙

| 기존 방법의 한계 | 새 방법 |
|---|---|
| 공간 맥락이 없거나 얕음 | CNN |
| 기억·지연 효과를 고려 안 함 | RNN, LSTM |
| 시간·공간 둘 다 | CNN + 순환 신경망, ConvLSTM |
| 먼 거리 공간 맥락 필요 (계절 예측) | 장거리 ConvLSTM |
| 물리 모델에 전적으로 의존 (수송 모델링) | **물리-합성곱 하이브리드** |

표가 분류 → 회귀 → 상태 예측으로 내려가며 **필요한 맥락이 늘어나고**, 마지막 줄에서 하이브리드가 예고된다.

### 5-2. Fig. 2 — 딥러닝 과제와 지구과학 과제 4쌍

| 딥러닝 | → | 지구과학 |
|---|---|---|
| a 물체 분류·위치 찾기 (개·고양이 박스) | → | 패턴 분류 (수증기 지도에서 극한 기상 박스) |
| b 초해상도 (8×8 얼굴 → 32×32) | → | 통계적 다운스케일링 (거친 격자 → 촘촘한 강수 지도) |
| c 비디오 예측 (다음 프레임) | → | 단기 예보 (다음 시점 지도) |
| d 언어 번역 (인코더-디코더) | → | 동적 시계열 모델링 (실제 vs 예측 습도) |

c의 `φ(X_t) → φ(X_t+1)`는 픽셀이 아니라 **추상 표현 공간에서 다음을 예측**하는 구조로,
4-1의 "추상적 피처 자동 추출" 정의와 맞닿는다.

## 6. 주요 구성 요소

### 6-1. 지구 데이터가 사진과 다른 점

```
채널       사진 3개(RGB) vs 초분광 위성 수백 개
통계       공간 의존성 + 변수 간 의존성 → i.i.d. 가정 위반
센서 통합  촬영 기하·해상도·물리적 의미가 제각각
결측       구름·눈으로 가려짐 → 무작위가 아니라 체계적
크기       512×512 vs 40,000×20,000 (약 3,000배)
라벨       ImageNet과 달리 없음. "이게 가뭄이다" 라벨은 개념적으로도 어려움
문제 성격  과소제약 → 학습·테스트는 통과해도 유효 범위 밖에서 무너짐 (외삽)
```

마지막은 물리 기반 지구 시스템 모델도 마찬가지라고 논문이 덧붙인다.

### 6-2. 도전 과제 5가지

| # | 과제 | 내용 |
|---|---|---|
| 1 | **해석 가능성** | 정확도만으론 부족. 자기 설명 모델과 인과 발견은 아직 멀다. 단, 복잡한 물리 모델도 가정을 되짚기 어려워 해석 가능성이 제한적이다 |
| 2 | **물리적 일관성** ★ | 관측은 잘 맞추지만 물리적으로 말이 안 되는 예측이 가능. 지배 법칙을 가르쳐 관측 제약 위에 이론 제약을 얹자 |
| 3 | 복잡·불확실한 데이터 | 복잡한 통계, 다중 출력, 다양한 노이즈, 고차원. **가까운 이웃 + 먼 거리 관계(텔레커넥션)** 를 함께 쓰는 새 구조 필요. 베이지안 추론 통합 |
| 4 | 라벨 부족 | 비지도 밀도 모델링, 피처 추출, 준지도 학습, 도메인 적응 |
| 5 | 계산 비용 | 구글 어스 엔진이 좋은 대응 사례 |

**2번이 하이브리드의 직접적 동기다.**

### 6-3. 물리 모델과 ML의 시너지 5지점 (Fig. 3)

Fig. 3은 지구 시스템 모델의 일부를 추상화한 그림이다. 색이 의미를 갖는다.

```
파란 상자   데이터 (Observations, Forcing, Ground truth)
회색 상자   물리 모델 쪽 (Parameters, Submodel, Output, Input)
황토 상자   머신러닝 쪽
빨간 동그라미 ①~⑤   ML이 끼어들 수 있는 지점

구조: [Forcing]→[Input] + [Parameters] → [Submodel] → [Output] → 다음 서브모델의 입력
```

| # | 이름 | 하는 일 | 예 |
|---|---|---|---|
| ① | **파라미터화 개선** | 제1원리로 못 구하는 파라미터를 관측·고해상도 모델에서 학습 | 식물 기능형 대신 공변량에서 학습 / 수천 유역에서 유출 파라미터 학습 / 대류의 거친 격자 파라미터 |
| ② | **서브모델을 ML로 대체** ★ | 이론적 근거가 약한 반경험 서브모델을 ML로 교체 = **하이브리드** | 물 수송은 확산 방정식(물리) + 기공 조절은 ML / 해수면 온도 |
| ③ | **모델-관측 불일치 분석** | 모델 오차의 패턴을 찾아 보정하고 이론을 개선 | 편향 보정, 다운스케일링 |
| ④ | **서브모델 제약** | 편향됐을 수 있는 다른 서브모델 대신 ML 출력을 입력으로 | 오차의 출처를 분리 |
| ⑤ | **에뮬레이션** | 물리 모델 전체·일부를 흉내 내 수십~수천 배 빠르게 | 복사 전달 모델 대체, 빠른 민감도 분석·보정 |

**현황:** ③은 이미 널리(벤치마킹·다운스케일링), ⑤도 널리(주로 효율 목적),
**② 하이브리드는 거의 빈 자리** — 논문이 밀고 싶은 방향.

### 6-4. 하이브리드 = 신경망을 더 깊게 (Fig. 4)

캡션의 핵심: **다층 신경망 뒤에 물리 층을 하나 이상 덧붙여 더 물리적으로 현실적으로 만드는 것.**

**a — 일반 구조** (아래에서 위로)
```
[Input] → 학습된 사상 1 → [단순 피처] → 사상 2..n+1 → [더 추상적 피처]
        → 사상 n+2 → [물리 모델 '파라미터'] → [물리 모델] → [물리적 출력]
                                              n = 신경망 층 수, m = 물리 층 수
```
신경망이 답을 바로 내지 않고 **물리 모델이 쓸 파라미터까지만** 만든다.

**b — 해수면 온도**
```
과거 온도장들 → 합성곱-역합성곱 신경망 → 움직임 장 → 물리적 변형 모델 → 미래 온도장
                (신경망은 "어디로 얼마나 흐르나"만 학습)   (온도를 실제로 옮기는 건 물리)
→ 열이 사라지거나 생기지 않는다
```

**c — 증산·광합성**
```
강수·복사·기온 시계열 → RNN 층 → 기공이 열린 정도의 시퀀스
                              → 물리 확산·에너지 균형 모델 → 증산, 광합성
                              → 그 결과가 토양 수분 같은 드라이버로 되돌아옴 (피드백)
잘 모르는 생물학적 조절 = ML / 잘 아는 확산 물리 = 물리 모델
```

### 6-5. 거꾸로 — ML 안에 물리 지식 넣기

| 방법 | 예 |
|---|---|
| 네트워크 구조 설계 | 물리 구조를 반영해 층을 구성 |
| **비용함수에 물리 제약** | 호수 온도 모델링에서 물리적으로 불가능한 예측에 벌점 |
| 물리 기반 데이터 증강 | 표본이 적은 영역을 물리 모델로 만들어 보탬 |

얻는 것: 성능·일반화 향상, **무엇보다 일관성과 신뢰성**, 부수적으로 **정규화 효과**
(물리가 말 안 되는 모델을 버리니 과적합을 더 잘 막는다. 특히 표본이 적거나 중간일 때).

### 6-6. 통합을 도울 두 방법론

```
확률적 프로그래밍     불확실성을 형식적·유연하게, 사전지식·제약 통합, 오차 전파가 자연스러움
                     → 근거 있는 불확실성 범위. 과학·정책 결정에 결정적인데 지금까지 거의 빠져 있었다

미분 가능 프로그래밍   자동 미분으로 효율적 최적화, 크고 비선형인 역문제를 다루기 쉽게,
                     민감도 평가로 해석 가능성에 도움
                     → 물리 층을 통과해서도 gradient가 신경망까지 흐르게 하는 열쇠
```

## 7. 근거 사례 (실험 대신)

Perspective라 통제된 실험이 없다. 대신 주장을 받치는 사례를 든다. **Ablation 해당 없음.**

| 사례 | 무엇을 보여주나 |
|---|---|
| 은닉층 1개 신경망이 CO₂ 플럭스의 하루·계절 변화를 예측하고 **봄철 뿌리 성장기의 호흡 증가**를 발견 | ML이 예측을 넘어 **새로운 과학적 사실**을 찾아냄. 당시 탄소순환 모델에 없던 패턴 |
| 전 지구 광합성·증발산을 순수 데이터 기반으로 정량화, 그 결과가 **물리 모델 평가의 벤치마크**로 쓰임 | ML 결과가 기준이 되고 물리 모델이 채점당하는 역전 |
| 딥러닝으로 수치예보 출력에서 **허리케인·대기의 강**을 탐지 | 임계값·주관적 라벨 없이 공간 모양만으로. 파트 2에서 어렵다고 한 문제를 푼 것 |
| 원격탐사 **도시 분류 정확도 95% 이상** | 다중 규모 피처 자동 추출의 효과 |
| **강수 나우캐스팅**에 합성곱-순환 결합 적용 | 공간+시간을 함께 쓰는 구조의 실제 적용 |
| ML 기반 광합성 추정이 **기후 모델의 열대우림 과대평가**를 지적 → 식생 덮개 복사 전달 이론 개선 → 다른 지역 추정도 개선 | **데이터 → 오류 노출 → 새 가설 → 이론 개선**의 완결 사례 |
| 데이터 기반 탄소순환 추정이 **고위도 CO₂ 계절 진폭 증가**의 수수께끼를 설명 (고위도 식생이 더 왕성) | 관측의 수수께끼를 ML이 설명 |
| 해수면 온도 하이브리드, 기공-확산 하이브리드 | 하이브리드가 실제로 작동하는 예 (Fig. 4b, c) |

## 8. 한계와 후속

### 8-1. 논문 자체의 한계

| 한계 | 내용 |
|---|---|
| 정량적 비교가 없다 | Perspective라 방법 간 성능을 통제된 조건에서 비교하지 않는다. 사례 나열에 기댄다 |
| 2019년 시점 | Transformer 기반 대형 모델과 자기지도학습이 본격화되기 전이다. "라벨 부족" 과제는 이후 자기지도학습으로 상당 부분 완화됐다 |
| 하이브리드 구현 방법이 구체적이지 않다 | "이렇게 합칠 수 있다"는 지도만 있고, 물리 층을 통과해 학습시키는 실제 절차는 미분 가능 프로그래밍 언급에 그친다 |
| 물리 모델과 ML 파라미터 동시 추정 | 논문도 "여러 서브모델을 바꾸면 복잡해진다"고 인정하고 해법은 열어둔다 |

### 8-2. 그 뒤에 일어난 일

| 예측 | 실제 |
|---|---|
| "딥러닝이 곧 시공간 구조 예측의 대표 방법이 될 것" | **맞았다.** GraphCast, Pangu-Weather, FourCastNet, FengWu 같은 데이터 기반 전 지구 예보 모델이 등장해 기존 수치예보와 경쟁 |
| "궁극 목표는 하이브리드" | **순서가 달랐다.** 순수 데이터 기반 대형 모델이 먼저 왔고, 하이브리드는 그 뒤에 왔다 |
| 하이브리드의 실현 | **NeuralGCM** (Kochkov et al., Nature 2024) — 기존 역학 코어(물리)에 ML 성분을 결합. 날씨 예측과 열대 저기압 계절 예측에서 성능을 내고, 기존 GCM 대비 계산을 수십~수백 배 아낀다. 다만 크게 다른 미래 기후로는 외삽되지 않는다 |

**Fig. 3의 ①②가 NeuralGCM에서 실제로 구현된 셈이다.** 논문이 그린 지도가 5년 뒤 현실이 됐다는 점에서
Perspective로서는 성공한 예측으로 볼 수 있다.

### 8-3. 권고 4가지 (Conclusion)

| 권고 | 내용 | 대응하는 도전 과제 |
|---|---|---|
| (1) 데이터의 특수성 인식 | 다출처·다규모·고차원·복잡한 시공간 관계, 특히 **시차 있는 먼 거리 관계(텔레커넥션)** 를 제대로 모델링. 여러 규모의 공간·시간 맥락을 함께 다루는 구조 개발 | ③ |
| (2) 타당성과 해석 가능성 | 정확할 뿐 아니라 **믿을 만해야** 한다. 파라미터와 피처 중요도가 최소한의 물리적 해석을 갖고, 모델이 규칙·관계로 환원·설명될 것 | ①② |
| (3) 불확실성 추정 | 모델이 자기 확신과 신뢰도를 밝혀야. 베이지안/확률적 추론 통합. **외삽 식별과 처리가 우선 과제** | ③ |
| (4) 물리 모델로 검증 | ML의 시공간 예측이 최소한 물리 모델의 패턴과 일관될 것. **물리 모델로 만든 합성 데이터**로 시험하라. 학습 데이터가 적거나 외삽을 평가할 때 특히 중요 | ② |

### 8-4. 궁극 목표

```
하이브리드 모델의 세 조건
  ① 물리 법칙을 따를 것
  ② 개념화된, 따라서 해석 가능한 구조를 가질 것
  ③ 이론이 약한 곳에서는 완전히 데이터 적응적일 것

ML도 자연과학의 물리 기반 관계에서 이득을 본다 (양방향)

풀어볼 난제
  대기 대류의 파라미터화
  기후와 상호작용하는 지구 요인에 대한 생태계의 시공간 의존성
```

## 9. 남은 질문 / 아쉬운 점

**읽으면서 걸렸던 것**

- **파트 2(기존 ML의 한계)를 글로는 따라갔지만 감각으로 잡히지 않았다.** "수작업 피처 vs 딥러닝 자동 피처"의
  차이를 다시 짚기로 했다. 특히 "왜 수작업이 최적이 아닌가"를 구체적인 예로 복습할 것.
- 지구과학 용어(플럭스, 데이터 동화, 파라미터화, 복사 전달)가 계속 걸렸다. 아래 배경 지식 표로 정리했다.
- Fig. 3은 색과 동그라미 위치를 알기 전까지 읽히지 않았다. 색이 데이터/물리/ML을 나눈다는 걸 먼저 잡아야 한다.

**논문이 답해주지 않는 것**

- **하이브리드를 실제로 어떻게 학습시키는가.** 물리 층을 통과해 gradient를 흘리는 구체적 절차는 없다.
- **언제 ML로 바꾸고 언제 물리를 남길지 판단하는 기준**이 없다. "이론적 근거가 약하면"이라고만 한다.
- **불확실성을 어떻게 검증할지**는 권고만 있고 방법이 없다.
- 2019년 이후 순수 데이터 기반 대형 모델이 먼저 성공한 것을 이 논문의 틀로 어떻게 볼지 — 하이브리드가
  여전히 궁극 목표인지, 아니면 규모가 물리 지식을 상당 부분 대체할 수 있는지는 열린 질문이다.

| 용어 | 뜻 | 왜 중요한가 |
|---|---|---|

| 데이터 동화 (data assimilation) | 관측값을 물리 모델에 계속 넣어 모델 상태를 현실에 맞게 보정 | 일기예보의 핵심. 과제 (2)의 비교 대상 |
| 원격탐사 | 위성·항공 센서로 반사·방출 복사를 재서 물체·변수를 추정 | 데이터의 주 출처 |
| 현장 관측 (in situ) | 땅 위·땅속·대기에서 직접 측정 | |
| CMIP | 전 세계 기후 모델이 같은 조건으로 돌린 결과 모음. IPCC 보고서 기반 | 모델 출력도 빅데이터 |
| 생물권 (biosphere) | 생물이 사는 영역. 숲, 토양, 해양 생태계 | 예측이 가장 어려운 영역 |
| 파라미터화 (parameterization) | 격자보다 작은 과정(구름·난류)을 간단한 식 + 파라미터로 대신 표현 | Fig. 3 ①, 후속 난제 |
| 식물 기능형 | 식생을 몇 유형으로 묶고 유형마다 같은 파라미터를 주는 관행 | ①이 겨냥하는 임기응변 |
| 서브모델 / 강제 변수 | 큰 모델 안의 부품 / 모델 밖에서 주어지는 입력 | Fig. 3 구조 |
| 복사 전달 (radiative transfer) | 빛이 대기·식생을 통과하며 흡수·산란·투과되는 과정의 모델 | ⑤ 에뮬레이션 대상, 열대우림 사례 |
| 증산 (transpiration) / 기공 (stomata) | 잎에서 수증기가 나가는 것 / 그걸 조절하는 잎의 구멍 | Fig. 4c |
| 텔레커넥션 | 수천 km 떨어진 곳끼리 기후 이상이 연결. 엘니뇨 → 북미 강수 | 권고 (1), 도전 ③ |
| 나우캐스팅 | 아주 가까운 미래 예측 (기상에선 2시간 이내) | Table 1 |
| 다운스케일링 / 편향 보정 | 거친 해상도를 촘촘하게 / 체계적 오차를 고치기 | Table 1, Fig. 2b |
| i.i.d. | 데이터가 서로 독립이고 같은 분포에서 나왔다는 가정 | 지구 데이터는 이 가정을 어긴다 |
| 과소제약 (under-constrained) | 데이터가 답을 하나로 좁히지 못해 여러 모델이 다 그럴듯한 상태 | 외삽 문제의 뿌리 |
| 초분광 (hyperspectral) | 빛을 수백 개 파장대로 잘게 나눠 재는 것 | 사진과 다른 점 |
| ConvLSTM | LSTM 내부 연산을 합성곱으로 바꾼 것. 지도의 시퀀스를 다룸 | Table 1의 주력 대안 |
| cGAN | 조건을 주고 그에 맞는 결과를 생성하는 GAN | 다운스케일링 대안 |
| 에뮬레이터 / 대리 모델 | 무거운 물리 모델을 흉내 내는 빠른 모델 | Fig. 3 ⑤ |
| 확률적 프로그래밍 | 확률 모델을 언어로 정의하면 추론이 자동으로 되는 방식 | 불확실성 |
| 미분 가능 프로그래밍 | 코드를 자동 미분해 파라미터를 최적화할 수 있게 짜는 방식 | 하이브리드 학습의 열쇠 |
| 램버시안 표면 | 밝기가 보는 각도에 무관한 표면. 컴퓨터비전의 고전적 가정 | 4-3 논증 |
| 강체 변환 | 모양은 그대로, 위치·방향만 바뀌는 변환 | 4-3 논증 |
| emergent constraints | 관측 가능한 양과 미래 예측의 관계로 예측 범위를 좁히는 방법 | 물리-ML 시너지의 선례 |

## [선택] 내 프로젝트 연계

| 논문의 개념 | lens에서 대응하는 것 |
|---|---|
| 순간·지점 값만 보면 안 된다, 상태는 과거에 흔적이 남는다 | 252일 lookback을 넣는 이유 |
| 공간 맥락 = CNN, 시간 기억 = LSTM, 둘 다 = 합성곱-순환 | `cnn_lstm.py`의 dilated conv + LSTM 구조 |
| 수작업 피처의 한계 | 36개 피처 중 이동평균·RSI 같은 기술적 지표가 전형적인 수작업 기억 피처. 논문 논리대로면 PatchTST·TiDE가 원시 흐름에서 스스로 뽑을 수 있어야 한다 |
| i.i.d. 가정 위반 | 시계열이라 이웃 시점이 독립이 아님 → 시간순 분할과 gap |
| **물리적 일관성 / 비용함수에 제약** | 밴드의 `q15 < q85`가 뒤집히지 않도록 넣은 **quantile crossing penalty**, 분위수를 누적합(softplus)으로 만들어 **구조적으로 순서를 보장**한 헤드 |
| 도메인 지식을 구조에 박기 | TiDE의 lookback skip — 신경망이 0을 내놔도 "과거의 선형 조합"이라는 기본 예측이 남는다 |
| 권고 (3) 불확실성 추정 | 점 예측이 아니라 밴드(q15/q85)를 내고 conformal로 커버리지를 맞추는 것 |
| 권고 (4) 물리 모델 합성 데이터로 검증 | 시뮬레이션 가격 시계열(급락장·횡보장)로 학습 기간에 없던 장세를 미리 시험해 보는 것에 해당 |

**VMD와의 대비** — VMD로 신호를 모드로 나눠 피처로 넣는 것은 이 논문이 말하는 **수작업 피처**에 해당한다.
사람이 "빈도 대역으로 나누면 좋을 것"이라고 설계한 것이기 때문이다. 이 논문은 그것을 딥러닝이
데이터에서 스스로 찾게 하자는 쪽이다. 다만 VMD처럼 **잘 이해된 신호 처리 지식**은 이 논문 기준으로도
물리 제약처럼 구조에 넣을 가치가 있어서, 둘이 꼭 배타적이지는 않다.

또 고위도 CO₂ **계절 진폭이 커지는 현상**은 VMD 관점으로 보면 계절 모드의 **진폭 변조(AM)** 다.
두 논문을 잇기 좋은 지점이다.
