## 1. 한 줄 요약

재귀적으로 하나씩 벗겨내던 EMD의 한계를 개선해, 신호를 **중심 빈도 근처에 몰린
좁은 대역 성분(모드) K개로 동시에** 나누는 방법. 샘플링과 노이즈에 강건하다.

---

## 2. 배경 — 이 논문이 나오기까지

신호를 성분별로 나누는 방법은 크게 두 흐름이 있었다.

```
EMD 계열 (경험적, 재귀)
  1998  EMD (Huang)                          봉우리·골짜기로 포락선을 만들어 하나씩 벗겨냄
    ├── 강건한 EMD                           포락선 보간을 제약 최적화로 대체. 재귀 구조는 유지
    ├── 부분 변분 EMD                         모드를 명시적으로 모델링. 여전히 보간·재귀
    └── 재귀 변분 분해                        Hilbert로 주 진동을 추정해 떼어내고 나머지에 반복

웨이블릿 계열 (고정·반고정 대역)
  2011  Synchrosqueezing (Daubechies 등)     웨이블릿 계수 중 중요한 것만 남겨 순간 빈도 복원
  2011  공명 기반 분해                        Q값이 다른 두 웨이블릿 기저로 지속 진동과 순간 변화를 분리
  2013  EWT (Empirical Wavelet Transform)    스펙트럼 봉우리로 대역을 나누고 필터뱅크 구성

  2014  VMD (이 논문)                        대역을 적응적으로 찾으면서, 모든 모드를 동시에 최적화
```

### EMD가 하는 일 — 포락선으로 벗겨내기

**포락선** = 파도의 봉우리 꼭짓점들을 부드럽게 이은 윤곽선. 진폭이 시간에 따라
어떻게 변하는지 보여준다.

```
① 봉우리 점들을 곡선으로 이음        → 위 포락선
② 골짜기 점들을 곡선으로 이음        → 아래 포락선
③ 두 선의 평균                      → 신호의 중심선 (느린 부분)
④ 원 신호 − 중심선                  → 빠른 출렁임 = 모드 하나
⑤ 남은 중심선에 ①~④ 반복            → 재귀 (sifting)
```

노이즈가 끼면 봉우리 위치가 흔들리고 → 포락선이 흔들리고 → 뽑은 모드가 틀어진다.
EMD가 노이즈에 약한 이유다.

## 3. 기존 방식의 한계

논문 I.C가 정리한 다섯 가지.

| # | 한계 | 해당 방법 |
|---|---|---|
| 1 | 수학적 이론 없이 임기응변(ad-hoc)으로 만든 알고리즘 | EMD |
| 2 | **재귀적으로 하나씩 벗겨내서, 앞의 오차를 되돌릴 수 없다** | 대부분 |
| 3 | 노이즈를 제대로 다루지 못한다 | EMD 계열 |
| 4 | 대역 경계가 딱딱하게 고정된다 | 웨이블릿 계열 |
| 5 | 필터뱅크 경계를 미리 정해야 한다 | EWT |

실험에서 드러난 EMD의 구체적 약점:

- **샘플링**: 빈도가 높을수록 한 번 반복에 찍힌 점이 적어 봉우리 위치가 흔들리고,
  오차가 빈도의 제곱으로 커진다 (Fig. 3)
- **가까운 빈도**: 빈도가 가까운 두 성분을 가르지 못하는 혼동 영역이 넓다 (Fig. 4)
- **노이즈**: 3개 성분 신호를 7개로 흩어놓고 어느 것도 순수한 사인파가 아니다 (Fig. 5)

## 4. 핵심 아이디어

### 4-1. 모드는 시간 조각이 아니다

모드는 **같은 시간에 겹쳐 있는 성분을 빈도 대역별로 가른 층**이다. 시간은 자르지 않는다.

```
시점           1    2    3    4    5    6    7    8
원 신호 f      +1   +1   +4   +1   +1   -3   -2   -3
───────────────────────────────────────────────────
모드 1 (느림)   0   +2   +3   +2    0   -2   -3   -2    ← 시간 전체
모드 2 (빠름)  +1   -1   +1   -1   +1   -1   +1   -1    ← 시간 전체
```

라디오로 비유하면 공중의 전파(원 신호) = 89.1 방송 + 91.9 방송 + 95.1 방송.
각 방송(모드)은 처음부터 끝까지 계속 나오고, 채널(빈도 대역)로 구분된다.

### 4-2. 모드의 정의를 바꾼다

| | 옛 기준 (EMD 원조) | 새 기준 (IMF, 이 논문) |
|---|---|---|
| 판정 | 모양을 **세서** | 모양을 **식으로** |
| 내용 | 극값 개수와 영교차 개수가 최대 1 차이 | `A(t)·cos(φ(t))` 꼴이고, 진폭 `A`와 빈도 `ω = φ'`가 **천천히** 변함 |
| 톱니파 | 통과 | 탈락 |

새 기준이 더 엄격하다. 새 기준을 만족하면 옛 기준도 만족하지만 반대는 아니다.

### 4-3. 천천히 변하면 대역이 좁다 → 중심 가정

진폭과 빈도가 천천히 변하면 카슨 법칙(식 3)에 따라 대역폭이 좁다.
**"모드는 좁은 대역이다"가 VMD의 중심 가정**이다.

### 4-4. 그래서 이렇게 나눈다

> 원 신호를 K개로 나누되 **다 더하면 원래가 되게** 나누고, 그런 나누기 중에서
> **각 조각을 자기 중심 빈도에서 0으로 옮겼을 때 가장 매끄러운 것**을 찾는다.
> 중심 빈도도 함께 찾는다.

재귀가 아니라 **모든 모드를 동시에** 조정하므로 오차를 모드끼리 나눠 갖는다.

## 5. 구조 / 방법

### 5-1. 목적함수 — 식(14)

```
min           Σ_k  ‖ ∂_t [ (δ(t) + j/(πt)) * u_k(t) ] · e^(−jω_k t) ‖²₂
{u_k},{ω_k}

subject to    Σ_k u_k = f
```

| 조각 | 뜻 |
|---|---|
| `(δ(t) + j/(πt)) * u_k(t)` | 모드의 해석신호. 음의 빈도를 지운다 (6-1) |
| `· e^(−jω_k t)` | 중심 빈도만큼 스펙트럼을 옮겨 0 근처로 (6-2) |
| `∂_t`, `‖·‖²₂` | 옮긴 신호의 기울기 제곱합 = 폭 점수 |
| `Σ_k` | 모든 모드의 폭 점수를 더함 |
| `{u_k}, {ω_k}` | 모드 K개의 모양과 중심 빈도 K개를 함께 찾음 |
| `Σ_k u_k = f` | 모드를 다 더하면 원 신호 |

**왜 이 점수가 좋은 분해를 고르나** — 원 신호 = 5 Hz + 30 Hz, K = 2

```
분해 A: 모드 1 = 5 Hz만,  모드 2 = 30 Hz만
        각자 0으로 옮기면 평평 → 폭 점수 ≈ 0        ✅

분해 B: 두 모드가 각각 5 Hz 절반 + 30 Hz 절반
        어디를 중심으로 잡아도 한 성분은 0에서 멀리 남음
        → 폭 점수 수백                              ❌
```

둘 다 "더하면 원 신호" 조건은 만족하지만 점수가 A를 고른다.

조건이 없으면 모든 모드를 0으로 만드는 게 1등(완벽히 평평)이 되므로
"다 더하면 원 신호"라는 울타리가 반드시 필요하다.

### 5-2. 조건 풀기 — 식(15) 증강 라그랑지안

```
L = α · Σ_k (폭 점수_k)  +  ‖ f − Σ_k u_k ‖²  +  ⟨ λ, f − Σ_k u_k ⟩
    └──── 매끄럽게 ───┘    └── 대략 맞추기 ──┘   └── 정확히 맞추기 ──┘
```

| 항 | 역할 |
|---|---|
| `α · 폭 점수` | 각 모드를 좁은 대역으로. α가 클수록 더 좁게 |
| 이차 페널티 | 모드 합과 원 신호의 차이를 제곱해 벌점. 계산을 안정시킴 |
| 라그랑지 승수 `λ` | 차이를 누적 메모해 조건을 정확히 지키게 함 |

이차 페널티만 쓰면 정확히 맞추려고 가중치를 무한대로 올려야 해서 계산이 불안정하고,
라그랑지 승수만 쓰면 수렴이 까다롭다. 둘을 합친다.

### 5-3. 풀이 — ADMM (Algorithm 2)

변수가 많아 한 번에 못 푸니 **하나씩 번갈아** 푼다. 전부 주파수 영역에서 계산한다.

```
처음: û_k = 0,  ω_k = 임의,  λ̂ = 0

반복:
  모든 k에 대해
    (27) û_k ← [원 신호 − 다른 모드들 + λ̂/2] × [ω_k 중심 필터]     ← 모드 갱신
    (28) ω_k ← û_k 스펙트럼의 에너지 무게중심                      ← 중심 갱신
  (29) λ̂ ← λ̂ + τ × (f̂ − Σ û_k)                                  ← 어긴 만큼 메모

멈춤: Σ_k ‖û_k(새) − û_k(이전)‖² / ‖û_k(이전)‖² < ε
끝:   역FFT의 실수부로 시간 신호 복원
```

**k-means와 같은 구조다.**

```
k-means                                  VMD
점을 가장 가까운 중심에 배정               빈도 성분을 가까운 중심의 필터가 가져감
중심을 배정된 점들의 평균으로 이동          중심을 가져간 에너지의 무게중심으로 이동
                                         + λ로 아무도 안 가져간 성분이 남지 않게 챙김
```

차이는 k-means가 딱 한 곳에 배정하는 반면 VMD는 필터로 부드럽게 나눠 가진다는 점.

**예시** — 신호 = 5 Hz + 30 Hz + 70 Hz, K = 3, 처음 중심 = 10, 40, 60

```
1회:  중심 → 7, 33, 66
2회:  중심 → 5.4, 30.8, 69.1
...
N회:  중심 → 5, 30, 70   변화 없음 → 멈춤
```

모드·중심에 대해선 최소, λ에 대해선 최대인 안장점(saddle point)에서 멈춘다.
더 좋은 분해로 바꿀 여지가 없는 균형점이다.

## 6. 주요 구성 요소

### 6-1. 해석신호 — 음의 빈도 지우기 (II.B)

실수 신호는 스펙트럼이 `+ω`와 `−ω` 두 곳에 대칭으로 있다.

```
cos(30t) = ( e^(j30t) + e^(−j30t) ) / 2      ← 반대로 도는 화살표 두 개
```

그냥 0으로 옮기면 `+30 → 0`, `−30 → −60`이 되어 한쪽이 멀어진다.
그래서 옮기기 전에 음의 빈도를 지운다.

**Hilbert 변환** `H`는 모든 cos를 sin으로 바꾸는 연산이다. 주파수 영역에서
양수 빈도엔 `−j`, 음수 빈도엔 `+j`를 곱한다.

**해석신호** `f_A = f + j·H[f]` 를 빈도마다 계산하면

```
양수 빈도:  1 + j × (−j) = 2   → 2배
음수 빈도:  1 + j × (+j) = 0   → 사라짐
```

- 해석신호는 길이 `A(t)`(포락선), 각도 `φ(t)`(위상)인 화살표 `A(t)·e^(jφ(t))`로 쓸 수 있다 (식 8)
- 모드의 진폭이 충분히 천천히 변하면 해석신호의 길이가 원래 진폭 그대로 나온다 (식 9, Bedrosian 정리)
- 실수부를 취하면 언제든 원래 신호로 되돌아간다 (식 10)

cos를 sin으로 바꾸는 이유는 sin 자체가 필요해서가 아니라 음의 빈도를 지우는 재료라서다.

### 6-2. 주파수 이동 (II.C)

실수끼리 곱하면 합과 차 두 빈도가 생긴다 (식 11).

```
cos(30t) · cos(30t) → 0 Hz 성분 + 60 Hz 성분
```

해석신호끼리 곱하면 지수가 더해질 뿐이라 한 빈도만 나온다 (식 12).
그래서 해석신호에 `e^(−jω_k t)`를 곱하면 스펙트럼 전체가 딱 `ω_k`만큼 이동한다 (식 13).

```
모드 (30 Hz 근처, 폭 ±3)  →  해석신호  →  × e^(−j30t)  →  0 근처, 폭 ±3 그대로
```

시간 그래프로 보면 **빨리 반복하던 파도를 반복하지 않게 늦추는 것**이다. 길이는 그대로다.
제대로 뽑힌 모드는 늦추면 평평해지고, 다른 빈도가 섞였으면 출렁임이 남는다.

### 6-3. 모드 갱신 = 위너 필터 (III.A)

**원형 — 식(5), (6)**: 노이즈 낀 `f₀`에서 원래 신호 복원

```
min_f  ‖f − f₀‖²  +  α · ‖∂_t f‖²          받은 값과 비슷하게 + 매끄럽게
       → 주파수로 풀면  f̂(ω) = f̂₀(ω) / (1 + α·ω²)
```

```
α = 0.01 일 때
ω = 0    → × 1.00   그대로
ω = 10   → × 0.50   절반
ω = 100  → × 0.01   거의 삭제
```

0 근처만 남기는 저역통과 필터다. 신호는 낮은 빈도에, 백색 노이즈는 모든 빈도에 퍼져 있다고
보면 높은 빈도를 깎을 때 노이즈가 주로 깎인다. α는 노이즈 분산 역할을 한다.

**VMD — 식(23)**: 이 필터의 중심을 `ω_k`로 옮긴 것

```
û_k(ω) =  [ f̂(ω) − Σ_{i≠k} û_i(ω) + λ̂(ω)/2 ]  /  [ 1 + 2α(ω − ω_k)² ]
           └──── 아직 아무도 안 가져간 나머지 ────┘      └─ ω_k 중심 필터 ─┘
```

모드 k는 나머지 신호 중 **자기 중심 근처 빈도만** 골라 가져간다.
논문이 VMD를 "위너 필터를 여러 적응형 대역으로 일반화한 것"이라고 부르는 근거.

### 6-4. 중심 갱신 = 무게중심 (III.B)

```
ω_k = Σ ω · |û_k(ω)|²  /  Σ |û_k(ω)|²

예: 에너지가 28 Hz에 1, 30 Hz에 3, 33 Hz에 1
    → (28 + 90 + 33) / 5 = 30.2
```

폭 점수는 중심에서 멀수록 벌점이므로 벌점이 최소가 되는 중심은 에너지의 무게중심이다.

### 6-5. 정확 복원 vs 노이즈 제거 (III.C)

| | λ | 결과 |
|---|---|---|
| 정확 복원 | 켬 | 모드 합 = 원 신호 (노이즈까지 전부 담음) |
| 노이즈 제거 | 끔 (`τ = 0`) | 모드 합 ≈ 원 신호 (노이즈는 흘려보냄) |

### 6-6. 경계 처리 — 거울 확장 (III.D)

푸리에 계산은 신호가 끝없이 반복된다고 가정하므로 **끝과 시작이 이어붙어 낭떠러지**가 생긴다.
톱니파와 같은 문제로 원래 없던 넓은 대역이 생긴다.

```
원래:         [ a  b  c  d  e  f ]
확장:  [ c  b  a | a  b  c  d  e  f | f  e  d ]
       └ 앞 절반 거울 ┘              └ 뒤 절반 거울 ┘
```

양 끝을 신호 길이의 절반씩 거울처럼 붙여 매끄럽게 잇는다 (Neumann 경계조건).

## 7. 실험 결과

### 7-1. 단일 톤 복원 (IV.A, Fig. 3)

사인파 하나를 257가지 빈도로 넣고 복원 오차를 본다.

- 세로축 오차(로그), 가로축 빈도, 동그라미 = VMD, 점선 = EMD 오차 상한
- (a)~(d)는 멈춤 기준 ε = 10⁻³, 10⁻⁵, 10⁻⁷, 10⁻⁹

**읽어야 할 패턴**
- EMD 상한(점선)은 빈도가 올라갈수록 커진다
- VMD(동그라미)는 빈도와 무관하게 가로로 평평하다
- ε를 줄일수록 동그라미 구름 전체가 아래로 내려간다
- 예외 두 가지: ε가 크면(a) 낮은 빈도에서 EMD 상한보다 나쁠 수 있고, Nyquist 근처에선 오차가 튄다

### 7-2. 두 톤 분리 (IV.B, Fig. 4)

```
f(t) = a₁·cos(2πν₁t) + a₂·cos(2πν₂t),   ν₂ < ν₁ < Nyquist,   ρ = a₁/a₂
```

- 행 3개 = 진폭 비 ρ = 1:4, 1:1, 4:1 / 열 2개 = EMD, VMD
- 삼각형 가로 ν₁, 세로 ν₂. 대각선에 가까울수록 두 빈도가 가깝다
- 흰색 = 오차 0, 검정 = 오차 0.5

| | EMD | VMD |
|---|---|---|
| ρ = 1:4 (느린 파도가 셈) | 거의 전부 검정 | 흰색 |
| ρ = 1:1 | 대각선 쪽 절반이 검정 | 흰색, 오른쪽 경계만 검은 선 |
| ρ = 4:1 (빠른 파도가 셈) | 전체 회색 | 흰색, 오른쪽 경계만 검은 선 |

VMD는 Nyquist 경계만 빼고 전부 가르며, 빈도가 가까워도 크게 나빠지지 않는다.

### 7-3. 노이즈 강건성 (IV.C, Fig. 5)

```
f(t) = cos(2 Hz) + ¼·cos(24 Hz) + ¹⁄₁₆·cos(288 Hz) + 노이즈(σ = 0.1)
```

가장 약한 성분(진폭 0.0625)이 노이즈(0.1)보다 작다. λ를 끄고 모드 3개로 분해.

| | 결과 |
|---|---|
| VMD 2 Hz | 거의 완벽 |
| VMD 24 Hz | 정답 점선과 거의 겹침 |
| VMD 288 Hz | 빈도는 맞게 찾았으나 모양에 노이즈가 많이 묻음 |
| VMD 중심 빈도 오차 | 0.27%, 1.11%, 0.18% |
| EMD | 7개로 흩어짐. 순수한 사인파에 해당하는 모드가 없음. EEMD도 크게 나아지지 않음 |

약한 성분이 어려운 이유는 α의 줄다리기다. α를 키우면 노이즈를 덜 담지만 중심을 놓칠 위험,
줄이면 중심은 찾지만 노이즈도 같이 담는다.

### 7-4. 초기값과 수렴 (IV.D, Fig. 6) — Ablation 성격

전역 최적해가 보장되지 않아 처음 중심값에 결과가 달라질 수 있다. 무작위 초기화 100회로 시험.

- 노이즈 작고(σ = 0.005) λ 켬 → **100% 성공**. 두 모드가 같은 성분을 잡고 한 성분이 잊혀도 λ가 결국 채움
- 노이즈 크면 λ가 오히려 방해 (노이즈까지 정확히 담으려 해서)
- λ 끄고 노이즈를 키우면 **적당한 노이즈에서 성공률 최대 90~95%**. 노이즈가 스펙트럼을 평평하게 해
  잘못된 해에서 빠져나오게 돕는다 (simulated annealing의 온도와 같은 효과). 더 크면 약한 성분이 묻혀 하락
- 가장 약한 성분도 **정답의 40% 오차 안에만 초기화**하면 성공

### 7-5. K 과소·과대 설정과 분해의 비유일성 (IV.E, Fig. 7, 8) — Ablation 성격

정답 3개 신호에 K = 2, K = 4로 실행.

| | α 작음 (대역 넓게) | α 큼 (대역 좁게) |
|---|---|---|
| K 모자람 | 한 성분을 이웃 모드가 나눠 가짐 | 한 성분이 노이즈 취급되어 버려짐 |
| K 남음 | 남는 모드가 노이즈만 담음 | 같은 성분을 두 모드가 중복, 중심이 겹침 |

모두 후처리로 알아챌 수 있다(스펙트럼 겹침, 남은 찌꺼기에 구조가 있는지). 자동 판단은 범위 밖.

**분해는 유일하지 않다.** 빈도가 아주 가까운 두 사인파는

```
cos(a·t) + cos(b·t) = 2 · cos((a−b)/2 · t) · cos((a+b)/2 · t)
                          └─ 느린 진폭 흔들림 ─┘  └── 중간 빈도 ──┘
```

사인파 2개로도, 진폭이 흔들리는 AM 신호 1개로도 볼 수 있고 둘 다 모드 정의를 만족한다(beat 현상).
VMD는 K와 α로 둘 중 어느 해석을 고를 수 있고, EMD는 항상 1개로만 본다.

### 7-6. 복잡한 신호 5개 (IV.F, Fig. 9~13)

| 예제 | 신호 | 결과 |
|---|---|---|

- aliasing: Nyquist를 넘는 성분이 낮은 빈도로 접혀 들어오는 현상

## 8. 한계와 후속

### 8-1. 논문이 인정한 한계 (V장)

| 한계 | 원인 | 논문의 대처 |
|---|---|---|
| **모드 개수 K를 미리 정해야 함** | k-means, EWT와 같은 구조 | 사전 정보 활용. 과소·과대 분할 증상이 예측 가능하니 자동 기준을 만들 수 있을 것 |
| **경계·갑작스러운 시작** | 기울기 벌점이 점프를 과하게 벌함 + 푸리에의 주기성 가정 | 거울 확장 (근본 해결 아님) |
| **강한 추세** | 주기적이지 않아 배음이 전 스펙트럼에 퍼짐 | 모드 하나의 중심을 0에 고정하는 옵션, VMD 전에 추세 제거 |
| **비정상 신호** (긴 EEG 등) | 시간에 따라 대역이 크게 바뀌고 겹침 | 짧은 창으로 잘라 창마다 VMD → 겹치게 가중 합산(OLA)으로 이어붙임 |

비정상 신호 대처에서 처음으로 시간을 자른다. 모드를 정의하는 방식이 아니라,
시간에 따라 빈도가 크게 바뀌는 긴 신호를 계산할 때 쓰는 요령이다.

**모드 직교성**: 스펙트럼이 겹치지 않는 신호는 서로 직교한다. VMD 모드는 스펙트럼이 대부분
안 겹치므로 거의 직교하게 나온다. 모드끼리 중복 정보를 거의 담지 않는다는 뜻이다.

### 8-2. 후속 연구

| 한계 | 후속 |
|---|---|
| 1차원만 가능 | **2D-VMD** (Dragomiretskiy & Zosso, 2015) — 저자들이 직접 이미지로 확장 |
| 채널이 여러 개인 신호 | **MVMD** (Multivariate VMD) — 여러 센서 채널의 공통 모드를 함께 추출 |
| K를 미리 정해야 함 | **SVMD** (Successive VMD, 2020) — 모드를 하나씩 순차 추출해 K 없이 분해. 이후 다변량(SMVMD, 2022)·2차원(2D-SVMD, 2025)으로 확장 |
| 예측에 쓸 때 미래 정보 누설 | **VMDNet** (2025) — 샘플마다 과거 구간만으로 분해하는 누설 없는 방식 제안 |

SVMD 계열은 VMD가 없앤 "순차 추출"을 다시 들여온 셈이다. 동시 최적화의 장점과
K 자동 결정 사이의 트레이드오프로 볼 수 있다.

## 9. 남은 질문 / 아쉬운 점

**읽으면서 걸렸던 것**

- **스펙트럼 그래프와 시간 그래프를 섞어서 봤다.** 사인파가 출렁이는 그래프를 스펙트럼으로 알고,
  위아래로 크게 움직이는 것을 대역폭으로 생각했다. 가로축이 시간이냐 빈도냐를 먼저 확인해야 한다.
- **모드를 시간 조각으로 오해했다.** K개로 나눈다는 말을 시간축을 K개로 자르는 것으로 이해했다.
  모드는 시간 전체를 가진 층이고, 시간을 자르는 건 비정상 신호를 다룰 때뿐이다.
- **"0으로 옮긴다"를 시간에서 일어나는 일로 생각했다.** 옮기는 건 주파수 축이다.
- **식(19)~(22) 유도를 따라가지 못했다.** 시작(19)과 결과(23)가 위너 필터 모양이라는 의미로만 이해했다.
- **그림 3~5를 혼자 읽지 못했다.** 축과 색의 의미를 설명받고 나서야 결론이 보였다.
  그림은 캡션 → 축 → 비교 대상 순으로 읽는다.
- 주파수를 음높이로 비유하면 오히려 헷갈렸다. 빈도(1초에 몇 번)로 이해하는 편이 맞았다.

**논문이 답해주지 않는 것**

- **α 값을 어떻게 고르나.** 노이즈 실험에서 α의 트레이드오프를 말하지만 선택 기준은 없다.
- **K를 자동으로 정하는 방법.** 증상으로 알아챌 수 있다고만 하고 범위 밖이라고 한다.
- **수렴 보장.** IV.D에서 자세한 수렴 분석은 범위 밖이라고 밝힌다.
- **예측에 쓸 때의 정보 누설.** 전체 구간을 한꺼번에 푸리에 변환하는 구조라 과거 구간 분해에
  미래 정보가 섞인다. 논문은 예측 용도를 다루지 않는다.

## [선택] 수학

### 식(1) — 모드

```
u_k(t) = A_k(t) · cos( φ_k(t) ),   ω_k(t) = φ_k'(t)
조건: A_k ≥ 0, ω_k ≥ 0, 그리고 A_k와 ω_k는 φ_k보다 훨씬 천천히 변함
```

한 주기(`δ ≈ 2π/φ_k'`) 정도만 떼어 보면 진폭 `A_k`, 빈도 `ω_k`인 순수한 사인파다.

### 식(2), (3) — 대역폭

```
BW_FM    = 2 · ( Δω + ω_FM )
BW_AM-FM = 2 · ( Δω + ω_FM + ω_AM )

Δω    빈도가 중심에서 최대 얼마나 벗어나나
ω_FM  그 벗어남이 얼마나 빠르나
ω_AM  진폭이 얼마나 빨리 흔들리나
```

진폭 흔들림이 옆 막대를 만드는 이유:

```
(1 + m·cos(ω_AM t)) · cos(ω_k t)
= cos(ω_k t) + (m/2)·cos((ω_k + ω_AM)t) + (m/2)·cos((ω_k − ω_AM)t)
```

### 식(5), (6) — 위너 필터

```
min_f  ‖f − f₀‖² + α‖∂_t f‖²      →      f̂(ω) = f̂₀(ω) / (1 + αω²)
```

미분이 주파수 영역에서 `ω` 곱하기가 되므로 빈도마다 나눗셈 한 번으로 풀린다.

### 식(8)~(13) — 해석신호와 이동

```
f_A = f + j·H[f] = A(t) · e^(jφ(t))       (8)
f   = Re[f_A]                               (10)
e^(jω₁t) · e^(jω₂t) = e^(j(ω₁+ω₂)t)         (12)
f(t) · e^(jω₀t)  ↔  f̂(ω − ω₀)               (13)
```

### 식(14) — 목적함수

```
min  Σ_k ‖ ∂_t [ (δ + j/πt) * u_k ] · e^(−jω_k t) ‖²₂    s.t.  Σ_k u_k = f
```

### 식(15) — 증강 라그랑지안

```
L = α Σ_k ‖∂_t[(δ + j/πt) * u_k] e^(−jω_k t)‖²₂ + ‖f − Σ_k u_k‖²₂ + ⟨λ, f − Σ_k u_k⟩
```

### 식(23), (26), (29) — 갱신식

```
û_k(ω) = ( f̂(ω) − Σ_{i≠k} û_i(ω) + λ̂(ω)/2 ) / ( 1 + 2α(ω − ω_k)² )      (23)

ω_k    = ∫₀^∞ ω |û_k(ω)|² dω  /  ∫₀^∞ |û_k(ω)|² dω                       (26)

λ̂(ω)  ← λ̂(ω) + τ ( f̂(ω) − Σ_k û_k(ω) )                                   (29)
```

극단값 확인:

```
α → 0    필터가 거의 평평 → 모드가 넓게 가져감 (노이즈도 담음)
α → ∞    필터가 극도로 뾰족 → 중심 빈도 하나만 가져감 (중심을 놓치기 쉬움)
τ = 0    λ가 계속 0 → 이차 페널티만 남음 → 노이즈 제거 모드
```

## [선택] 내 프로젝트 연계

**기후 스터디 (교수님 10편 중 기후 5편)**

논문 Introduction이 EMD 계열의 응용 분야로 기후 분석을 명시한다.
기후 기록은 대표적인 섞인 신호다.

```
기온 기록 = 장기 추세 + 수십 년 주기 진동 + 계절 주기 + 날씨 변동 + 노이즈
```

주의점은 VMD 한계와 그대로 겹친다.
- 장기 추세가 강하면 VMD 전에 제거
- 수십 년 기록은 비정상 신호라 창 분할(OLA) 필요
- 계절 주기처럼 사전 지식이 있으면 K와 초기 중심을 정하기 쉬움

**lens (주가 예측)**

"VMD로 분해 → 모드별 예측 → 합산" 방식이 흔하지만, VMD는 전체 구간을 한꺼번에 푸리에 변환하므로
과거 구간을 분해할 때 미래 정보가 섞인다. 백테스트 성능이 부풀려진다.
쓰려면 매 시점마다 그 시점까지의 데이터로만 다시 분해해야 한다 (8-2 VMDNet 참고).
